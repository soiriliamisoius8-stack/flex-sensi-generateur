# flex-sensi-generateur
 Il s'agit d'une application web (Web App) de divertissement et d'optimisation destinée à la communauté du jeu mobile Free Fire. Le site propose un outil interactif permettant aux joueurs de générer des configurations de sensibilité tactiles personnalisées (DPI, sensibilité générale, viseurs 2x et 4x) adaptées à la marque et au modèle du téléphone
